# 📄 ML-Doc-Processing-Hackathon

Streamlit app for the Boon AI Hackathon focused on PDF document processing, LLM-based field extraction, and schema-aligned entity mapping.

## Features
- Upload PDFs, JSON schemas, and markdowns
- Extract fields using GPT or Claude
- Perform schema validation and entity mapping
- Manual editing and export of merged results

## Run the App
```bash
streamlit run main.py
